## Remaining items (blocked this session — need Framer-side follow-up)

The Framer MCP plugin could only serialize the **currently focused page** (the homepage). Every other page and every component (`Footer`, `Client Testimonial Card`, `Pill Label`, contact/waitlist/franchising pages, etc.) returned a serializer error ("Node is not a text node"), so these could not be fixed remotely:

1. **11 missing form labels** — these are Framer-native form inputs (contact, waitlist, franchising/catering forms, footer newsletter). In Framer: select each input → add a visible label or set the Name/aria-label on the input. Placeholder text alone does not count as a label.
2. **Remaining contrast errors (~106 instances)** — the two color-style fixes above will clear every instance bound to `/Teal - Primary` and `/Grey`, but instances with hard-coded colors inside components (testimonial cards, footer links on dark, orange accent text using `/Orange` `rgb(255,106,12)` / `/Theme Color 2` `rgb(255,131,66)`) need per-component review. Orange-on-cream fails AA (~2.4:1); if used as text, darken toward `rgb(178, 64, 0)` or reserve for large/decorative text.
3. **Very small text (1 alert)** — likely `/Body Small` (0.8rem) or a smaller one-off inside a component; bump to ≥0.875rem where flagged.
4. **Redundant link / noscript / HTML5 video alerts** — hero background video is decorative and muted; keep it `aria-hidden` and ensure it has no keyboard trap. Merge adjacent duplicate links pointing at the same URL.
5. **Duplicate color styles** — two styles share the path `/Grey` (113 → now 90, and a second at `rgb(153,153,153)`), and three share `/White`. The duplicate `/Grey` at 153 cannot be targeted via MCP; rename/merge duplicates in Framer's style panel.
